这是什么

OpenWorker是一款开源的桌面AI助手软件，由Andrew Ng团队开发。它不是一个简单的聊天机器人，而是一个能真正帮你完成日常工作的智能同事。与传统AI对话工具不同，OpenWorker运行在你自己的电脑上，能够访问你的文件、终端和各种常用应用（如Slack、GitHub、Jira、Notion、日历等），把复杂任务拆解成步骤并执行，最终交付完整成果。它支持多种AI模型提供商，包括OpenAI、Anthropic、Google Gemini，也支持本地运行的开源模型。所有数据都保存在本地，只有你选择的模型API才会接收必要信息。项目采用Python后端+React前端+Tauri桌面壳的技术栈，支持macOS和Windows，具备自动更新能力。

核心功能

  • 本地运行，隐私优先，数据不离开你的电脑
  • 25+应用集成，覆盖主流办公工具
  • 支持多种AI模型，自带密钥即可切换
  • 任务执行前需人工确认，安全可靠

能用来做什么

适合需要处理大量日常办公任务的职场人士。比如：每天早上让AI整理邮件和日程，生成简报；在Slack群里@AI让它查数据并回复；让AI监控GitHub和Jira上的项目进展，定期汇报；自动整理本地文件，生成报告或文档。对于经常需要在多个应用间切换、处理重复性工作的用户，OpenWorker能显著减少手动操作时间，把精力集中在真正需要判断和决策的事情上。

技术亮点

OpenWorker的技术架构有几个亮点：一是基于aisuite库构建，统一了不同AI模型的调用接口，用户可灵活切换；二是采用MCP（Model Context Protocol）协议，任何支持该协议的第三方工具都能接入；三是本地优先设计，所有密钥、对话记录、连接器凭证都存储在本地安全存储中，仅OAuth握手时短暂连接云端；四是支持语音输入（Rust编写的STT侧车）；五是桌面应用使用Tauri框架，比传统Electron应用更轻量。整体采用Python后端+React前端+Rust组件的混合架构，兼顾开发效率和运行性能。

如何上手

访问openworker.com下载macOS或Windows版本，安装后打开应用，输入你选择的AI模型API密钥（或配置本地Ollama），然后直接告诉它你想完成什么任务即可。如果想从源码运行，需要Python 3.10+、Node 20+和Rust工具链，执行setup脚本后分别启动服务端和GUI即可。建议先从简单的文件整理或日程安排任务开始体验。
