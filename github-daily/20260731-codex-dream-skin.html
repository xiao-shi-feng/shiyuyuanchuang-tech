这是什么

Codex Dream Skin 是一个专为 Codex 桌面客户端设计的主题换肤工具，它允许用户通过外部注入的方式改变界面外观，而无需修改官方安装包或二进制文件。项目支持 macOS 和 Windows，提供丰富的社区主题库（DreamSkin.cc），用户可在线预览、一键换肤或导入自定义主题包。其核心理念是「一张图，一种心情」，让开发者在编码时拥有个性化、沉浸式的视觉体验。所有操作均基于本地 CDP 注入，安全可控，不触碰 API 配置或模型设置，适合追求美学与效率兼顾的开发者。

核心功能

  • 真·可交互：侧栏、输入框等均为原生控件，非静态贴图
  • 真背景层：16:9 全屏壁纸自动适配焦点与安全区
  • 一键换肤：网页触发本地安装，带完整校验与恢复机制
  • 主题创作 Studio：浏览器内编辑配色、背景、CSS，导出 ZIP

能用来做什么

适用于日常编码、创意写作、系统调试等需要长时间面对 IDE 的场景。开发者可根据心情切换不同风格——如哥特科幻、日系清新、极简白昼等，提升专注力与愉悦感。同时支持个人背景图导入，结合 AI 生成素材打造专属工作台。对于团队协作或个人品牌展示，统一主题也能增强视觉识别度。无论是深夜 coding 还是晨间灵感迸发，都能让屏幕成为你的情绪延伸。

技术亮点

项目采用本地回环 CDP（Chrome DevTools Protocol）注入技术，在不修改官方 App 的前提下实现深度样式定制。所有主题包包含 `theme.json`、`theme.css` 与背景图，并通过 SHA-256 校验确保完整性；Safe CSS 限制仅作用于 12 个注册部件，避免破坏 UI 结构。一键换肤流程中，网页链接携带唯一版本 ID，App 主动拉取并验证签名，防止恶意注入。此外，macOS 菜单栏与 Windows 托盘提供实时主题管理，支持保存、切换、还原，甚至手动移动主题目录至本地路径，兼具灵活性与安全性。

如何上手

普通用户无需编程基础，直接从 GitHub Releases 下载对应平台安装包（.dmg 或 .exe），按向导完成一次安装后退出官方 Codex。首次启动时若遇安全提示，依文档放行即可。安装后从菜单栏或托盘选择「导入主题 ZIP」或访问 dreamskin.cc 浏览社区主题，点击「一键换肤」即可应用。开发者可运行脚本从源码构建，或参考 docs/ 中的提示词与模板生成自己的背景图。建议优先使用 v1.5.5+ 客户端以支持完整功能。
