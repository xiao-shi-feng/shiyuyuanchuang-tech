这是什么

Decimen Optical Transfer 是一个基于浏览器的开源文件传输工具，它利用屏幕显示和摄像头拍摄之间的光信号通道，实现两台设备之间的文件传输，完全不需要网络连接、蓝牙配对或任何额外的应用程序安装。其核心原理是将文件数据编码成一系列动态的二维码帧，发送端设备将这些帧以动画形式在屏幕上连续播放，接收端设备则通过摄像头实时捕捉这些画面，并利用 fountain 编码技术（一种容错编码方式）从捕捉到的任意足够数量的帧中还原出原始文件。这意味着即使部分帧因为光线、角度或遮挡而丢失，只要接收端收集到大约 115% 的数据量，就能完整恢复文件，不会出现数据损坏。项目支持最高 64MB 的文件传输，自动保留文件名和媒体类型，并在传输前进行完整性校验。目前实测在高性能显示器与旗舰手机之间，可持续传输速度达到约 418.5 KB/s，峰值可达 601.5 KB/s，足以在几秒内传输一张高清照片或一段短视频。整个系统完全在浏览器中运行，无需服务器中转，保护用户隐私，适合在无网络环境或需要避免网络暴露的场景下使用。

核心功能

  • 零网络依赖：无需 Wi-Fi、蓝牙或互联网，仅靠屏幕和摄像头即可完成传输
  • 即开即用：纯 Web 应用，无需安装 App，支持离线使用，iOS 和 Android 可添加至主屏幕
  • 高容错传输：采用 fountain 编码技术，丢帧不影响文件完整性，只需收集约 115% 的帧数据
  • 安全隐私：无网络路径，数据不经过任何服务器，仅通过光信号直接传输，SHA-256 校验保障完整性

能用来做什么

该项目适用于多种无网络或需规避网络风险的场景。例如，在飞机、地铁等信号屏蔽环境中，用户可通过此方式在个人设备间快速分享照片、文档或视频；在涉密单位或高安全要求场合，员工可在物理隔离的网络环境中，通过屏幕与摄像头的光信号通道传输敏感文件，避免数据外泄；记者或摄影师在野外采风时，可将拍摄素材从相机屏幕传至手机，无需携带数据线或依赖云端同步；此外，在设备蓝牙或 NFC 功能故障时，也可作为应急替代方案。其最大价值在于提供了一种简单、无需配置、跨平台且隐私安全的文件传输途径，尤其适合临时性、小批量、高敏感性的数据交换需求。

技术亮点

该项目的核心技术亮点在于其创新的屏幕-摄像头光信道设计与 fountain 编码的结合。由于屏幕到摄像头的链路是单向且无反馈的，传统重传机制无法使用，因此项目采用 Luby 变换 fountain 编码，将文件分块并生成冗余编码帧，接收端只需收集任意 K×1.15 个独立帧即可解码还原，丢帧仅影响速度而不影响正确性。视频流在页面中可直接播放，提升用户体验。项目基于 TypeScript 构建，使用 node-qrcode 生成二维码，并集成自定义编译的 zxing-cpp 解码器，确保在浏览器端高效处理。性能方面，通过优化编码帧率与解码算法，在高端设备组合下实现 418.5 KB/s 的持续吞吐量，峰值达 601.5 KB/s。项目还提供详细的诊断报告与基准测试工具，支持本地开发、独立部署及离线安装，架构清晰，文档完善，体现了工程化与学术研究的良好结合。

如何上手

访问 https://decimen.app 即可在两台设备上直接使用，无需安装。发送端打开网站后选择文件或粘贴文本，生成动态二维码流；接收端用摄像头对准屏幕，自动开始接收并解码。若需本地运行，可克隆仓库后执行 npm install，再通过 npm run dev 启动开发服务器，在发送端访问 https://localhost:5173/send/，接收端通过打印的网络 URL 访问（需接受自签名证书）。建议使用高分辨率屏幕和性能良好的手机摄像头以获得最佳传输速度。项目支持离线使用，首次访问后可安装为 PWA 应用。详细教程可查看 docs/user/quick-start.md。
