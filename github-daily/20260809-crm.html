想象一下，你雇了一个不知疲倦的助理，他每天自动帮你整理客户资料。传统的客户管理系统就像一个大档案柜，需要你自己去填表格。而这个系统不一样，它请了一位智能助理，这位助理会自己主动去查资料、记笔记、安排回访，甚至在你关电脑后还在工作。你只需要告诉它目标，它就会自己规划路线，把收集到的信息整理好放在柜子里。如果它不确定某个信息是否准确，会标注出来让你确认，而不是瞎猜。

这是什么

这是一个专为AI智能体设计的开源客户关系管理系统。与传统CRM不同，它不是给人用的数据库表单，而是让AI助手作为核心。系统包含一个独立部署的智能体应用，基于Eve框架构建，拥有18个工具、4项技能和自动调度机制。智能体会自主决定下一步查什么、何时回访、如何记录证据，并在预算用尽时停止。它强调'不猜测任何人的信息'，所有工具只报告观察到的事实，弱证据变成建议由人类确认。系统支持多种外部数据源（如LinkedIn、Web搜索），但即使没有API密钥也能运行，因为自身邮件和会议记录就是最可靠的证据。前端使用Next.js，后端用NestJS，数据存PostgreSQL，整体采用TypeScript技术栈。

核心功能

  • 智能体自主运行：独立调度、自动规划工作队列、预算耗尽自动停止
  • 零猜测原则：只记录观察到的事实，弱证据转为人类确认建议
  • 透明可追溯：每个客户记录都有Agent标签页，实时查看智能体工作步骤
  • 沙箱安全隔离：无网络无数据库权限，防止数据外泄

能用来做什么

适合销售团队、客户成功团队或任何需要维护大量客户信息的场景。当销售代表忙于拜访客户时，智能体可以自动研究潜在客户背景、更新公司资料、安排跟进提醒。比如，智能体发现某客户公司换了新CEO，会自动记录并建议销售代表祝贺。对于中小企业，可以部署一套系统让AI助手24小时维护客户数据，减少人工录入错误。同时，由于支持无API密钥运行，初创团队可以用零成本启动，仅依赖内部邮件和会议记录就能建立基础客户档案。

技术亮点

技术架构极具特色：采用Monorepo结构，Agent独立部署在Eve框架上，利用其文件系统优先的特性实现持久化会话。核心创新在于'证据定价'机制——工具只报告观察值（如签名档、GitHub账号），由账本系统评估证据强度，强证据直接写入记录，弱证据转为待确认建议。安全方面，沙箱环境deny-all出站策略，且永远不注入数据库凭证，Shell命令只能作为文本处理器。前后端通过tRPC实现端到端类型安全，前端URL状态管理让分享视图如同分享链接。单租户设计刻意移除组织字段，避免冗余索引和权限检查。

sh
git clone https://github.com/trycompai/crm.git && cd crm
cp .env.example .env          # then fill in the values below
bun install

docker compose up -d          # Postgres on :5432

bun run db:deploy             # apply migrations
bun run db:seed               # optional: a believable pipeline to look at
bun run dev

如何上手

需要Bun运行时和Docker环境。首先克隆仓库并进入目录，复制.env.example为.env并填写必要配置（如BETTER_AUTH_SECRET、ALLOWED_SIGN_IN邮箱域名）。选择Google或Microsoft OAuth之一配置登录。运行docker compose up -d启动PostgreSQL，执行bun run db:deploy应用数据库迁移，可选bun run db:seed填充示例数据。最后bun run dev启动开发服务器，前端访问localhost:3000，API在3001端口。注意release分支为稳定版，main分支含未发布功能。
