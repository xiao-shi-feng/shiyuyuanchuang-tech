这是什么

MediaCrawler 是一款功能强大的多平台自媒体数据采集工具，支持小红书、抖音、快手、哔哩哔哩、微博、百度贴吧和知乎等七大主流平台的公开信息抓取。它能爬取笔记、视频、帖子内容，以及二级评论，还能生成词云图。与传统的爬虫需要破解复杂加密不同，它利用浏览器自动化技术，通过保存登录状态的方式获取数据，大大降低了使用门槛。项目提供命令行和可视化界面两种操作方式，数据支持保存为 CSV、Excel 或数据库格式，适合个人学习、市场研究或内容分析使用。

核心功能

  • 七平台全覆盖：支持小红书、抖音、快手、B站、微博、贴吧、知乎
  • 无需逆向破解：基于浏览器自动化，保留登录态，避开复杂加密
  • 双模式操作：提供命令行工具和 Web 可视化界面，易用性高
  • 多功能采集：支持关键词搜索、指定 ID 爬取、二级评论获取及词云生成

能用来做什么

适合市场营销人员追踪热点话题，内容创作者分析竞品爆款，学术研究者收集社交媒体数据进行情感分析，以及自媒体运营者监控品牌舆情。通过批量获取公开评论和帖子，用户可以快速了解用户喜好、挖掘潜在趋势，为内容决策提供数据支撑，无需手动翻阅大量页面，大幅提升信息收集效率。

技术亮点

核心技术基于 Playwright 浏览器自动化框架，采用 CDP 模式连接用户已有 Chrome 浏览器，复用登录态和 Cookie，有效降低风控风险。无需逆向 JS 加密算法，通过注入 JS 表达式获取签名，大幅降低技术门槛。支持多账号、IP 代理池，具备断点续爬能力（Pro 版），架构设计解耦，代码易读易维护，适合学习企业级爬虫项目设计思路。

示例速览

shell
# 进入项目目录
cd MediaCrawler

# 使用 uv sync 命令来保证 python 版本和相关依赖包的一致性
uv sync
shell
# 仅在标准 Playwright 模式下需要安装浏览器驱动
uv run playwright install

如何上手

首先安装 Python 和 Node.js 环境，推荐使用 uv 管理依赖。安装最新版 Chrome 浏览器并开启远程调试模式。克隆项目后运行 uv sync 安装依赖，修改 config/base_config.py 配置平台和关键词，执行 uv run main.py 即可开始爬取。也可启动 WebUI 界面进行可视化操作。注意仅限学习研究使用，请勿用于商业用途。
