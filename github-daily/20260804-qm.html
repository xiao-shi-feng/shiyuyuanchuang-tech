这是什么

QM是一个专为初创公司设计的多人AI代理工作平台。传统AI助手通常只为个人服务，但QM让整家公司都能用上AI——每个员工拥有独立的工作空间，包括专属的记忆、文件、定时任务和权限设置，彼此隔离互不干扰。同时，员工又能在Slack频道、群聊或项目空间中与AI协作。它支持多种AI驱动框架，用户可自由选择底层模型，部署不绑定单一供应商。平台提供Web界面和Slack集成，员工可在两者间无缝切换，身份和配置保持一致。管理员能统一设置安全策略、可用工具和模型范围。QM采用插件化架构，核心是通用的，公司特有的配置、工具和技能都放在部署目录中，通过CLI初始化和验证。安全方面提供三种模式：严格模式需人工审批每个操作，自动模式由分类器筛查外部数据，危险模式则完全放开。所有操作都有审计日志。

核心功能

  • 个人与共享双轨工作空间——每个人有独立AI助手，同时支持团队协作
  • Slack与Web无缝切换——同一身份和配置在两个平台间自由切换
  • 灵活的安全策略——严格/自动/危险三级控制，所有操作可审计
  • 多框架兼容——支持Pi、OpenCode、Codex、Claude Code等多种AI驱动

能用来做什么

初创公司日常运营中，QM能大幅提升效率。员工可以用它搜索内部文档、邮件和数据库，快速找到所需信息。AI能学习你的写作风格，自动整理收件箱并生成回复草稿。开发团队可以让AI在仓库中运行测试、创建PR、监控CI状态。项目管理时，AI能在共享频道中跟踪进度、发布更新和提醒后续事项。公司还能用QM搭建内部应用，定向发布给相关人员，并保持数据实时更新。定时任务功能让AI在无人值守时也能持续工作，比如定期整理数据或发送报告。

技术亮点

QM采用插件化架构设计，核心引擎完全通用，所有公司特定配置、工具和技能都封装在部署目录中，通过CLI进行验证和部署。这种设计让不同公司的实例可以独立定制，同时保持核心代码的一致性。安全模型借鉴了本地编码代理的思路，AI以员工身份操作，所有行为可审计。三种安全模式（严格/自动/危险）满足不同场景需求，预定义命令策略确保即使危险模式下也不会执行递归删除等危险操作。技术栈采用TypeScript + Node.js + Fastify构建HTTP服务，Slack插件使用Bolt框架，Web界面基于Vite和Lit渲染。PostgreSQL作为持久化存储，管理会话、记忆和队列。每个作用域都有独立的沙箱环境，确保工具安装和运行隔离。

如何上手

使用QM需要创建组织级别的部署仓库。首先运行初始化命令，指定组织标识和目标云平台（Fly或AWS），CLI会引导完成基础设施配置、Web登录、连接器凭证设置和Slack集成等步骤。整个过程无需克隆源码仓库。初始化完成后，部署运行在运营商自己的云账户中。对于需要深度定制的组织，可以创建私有分支，将完整代码库放在一处，工程师和AI代理可以共同阅读核心代码和自定义内容。通过update-qm技能可以合并上游更新，通过upstream-pr技能可以将通用修复提交回主仓库。
