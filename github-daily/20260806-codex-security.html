这是什么

Codex Security是OpenAI推出的代码安全扫描工具，包含命令行工具和TypeScript开发包两部分。它专门用于发现、验证和修复代码中的安全漏洞。与传统的安全扫描工具不同，它内置了人工智能能力，能够像一位经验丰富的安全专家一样理解代码逻辑，找出潜在的安全风险，并直接给出修复方案。工具支持多种AI模型提供商，包括OpenAI、Anthropic、AWS Bedrock等，用户可以根据需求灵活选择。扫描结果会以报告形式保存，方便团队查看和追踪。工具还具备比较功能，可以对比两次扫描的结果，自动识别新增漏洞、已修复问题和持续存在的问题。对于企业用户，还支持容器化批量扫描，可以在持续集成环境中自动化运行安全检测。

核心功能

  • AI智能扫描与自动修复，不仅能发现问题还能直接给出解决方案
  • 支持多模型提供商，可灵活选用OpenAI、Anthropic、AWS Bedrock等
  • 扫描结果对比功能，自动追踪漏洞的新增、修复和复发状态
  • 容器化批量扫描支持，适配企业级持续集成工作流

能用来做什么

这个项目非常适合软件开发团队在代码上线前进行安全审查。比如，你在开发一个网站或移动应用，上线前可以用它全面扫描代码，找出可能泄露用户数据或容易被攻击的漏洞。对于企业安全团队，可以在持续集成流程中自动运行扫描，确保每次代码更新都不会引入新的安全风险。此外，安全研究人员也可以用它在大规模代码库中快速定位高危漏洞。相比传统安全工具，它的优势在于不仅能发现问题，还能直接修复，大大节省了人工排查和修复的时间成本。

技术亮点

Codex Security的技术架构有几个显著亮点。首先，它采用多智能体协作模式，支持深度扫描模式，可以配置工作线程数和子代理数量，实现并行化安全分析。其次，工具内置了智能停止机制，当连续多次扫描未发现新漏洞时自动终止，避免无效计算。第三，它支持多种认证方式，包括ChatGPT登录和API密钥，且CI环境中使用的API密钥不会持久化存储，保障凭证安全。第四，工具提供了详细的诊断日志功能，可通过环境变量控制日志级别，帮助开发者排查问题。最后，它支持知识库共享功能，可以将安全文档传递给所有扫描任务，实现企业级安全知识沉淀。

示例速览

bash
npm install @openai/codex-security
npx @openai/codex-security login
npx @openai/codex-security scan .
npx @openai/codex-security scan . --model gpt-5.6-terra --effort high
npx @openai/codex-security scan . --mode deep --workers 2 --subagents 0 --stop-after-no-new 3 --max-discovery-runs 10

如何上手

使用Codex Security非常简单。首先确保你的电脑安装了Node.js 22.13.0以上版本或Node.js 24/26版本，以及Python 3.10以上版本。然后运行npm install安装工具包，接着执行登录命令完成身份验证。最后使用扫描命令对目标代码目录进行检测，可以指定扫描模式和使用的AI模型。对于持续集成环境，只需设置对应的API密钥环境变量即可自动运行扫描，无需交互式登录。
