想象一下，你手头有一堆不同格式的文档——有的像Word写的报告，有的像PPT做的演示文稿，还有的像Excel表格，甚至可能有PDF文件。这些文档格式各不相同，就像不同的语言一样，很难统一处理。anydoc就像一个万能翻译官，不管你把什么格式的文档丢给它，它都能快速准确地翻译成同一种格式——Markdown。这个工具特别快，处理一份文档只需要几毫秒，比眨眼还快。而且它支持十几种不同的文档格式，包括Word、PPT、Excel、PDF等等，几乎涵盖了所有常见的办公文档类型。

这是什么

anydoc是一个高性能的文档转换工具库，由Rust语言编写，能够将多种办公文档格式统一转换为Markdown格式。它支持Word（.doc/.docx/.docm）、PowerPoint（.ppt/.pptx等）、Excel（.xls/.xlsx等）、OpenDocument、RTF、EPUB、CSV和PDF等十几种格式。这个工具的核心价值在于'统一输出'——无论输入什么格式的文档，都会通过一个共享的文档模型，最终输出格式一致的Markdown。这意味着文档中的标题、列表、表格、图片、脚注等内容都会被完整地保留和转换。anydoc由Firecrawl公司开发，主要用于将办公文档转换为大语言模型可处理的格式。它提供了多种使用方式：命令行工具、Node.js库、Python库和WebAssembly浏览器版本，满足不同开发场景的需求。

核心功能

  • 极速转换：纯Rust编写，中位转换时间不到5毫秒，比竞品快一个数量级
  • 全格式支持：唯一支持全部14种格式的转换工具，涵盖所有常见办公文档
  • 智能格式检测：根据文件内容自动识别格式，即使文件扩展名错误也能正确转换
  • 多语言绑定：提供Node.js、Python、Rust和WebAssembly四种绑定，适配不同开发场景

能用来做什么

anydoc非常适合需要批量处理文档的场景。对于企业用户，可以将历史文档库中的各种格式文件统一转换为Markdown，便于后续归档和分析。对于AI应用开发者，可以快速将用户上传的文档转换为大语言模型可处理的格式，提升应用效率。对于内容创作者和知识管理者，可以将不同来源的文档统一格式，建立标准化的知识库。此外，anydoc还支持Agent技能集成，让AI助手能够直接读取和处理各种文档格式，扩展了智能助手的能力边界。

技术亮点

anydoc采用纯Rust实现，不依赖机器学习模型或外部服务，确保转换过程快速且隐私安全。它通过内容检测而非文件扩展名来判断格式，有效处理了命名不规范的文件。文档模型支持完整的结构保留，包括标题锚点、嵌套列表、合并单元格表格、脚注和演讲者备注等。Node.js绑定在libuv线程池中运行，不会阻塞事件循环；Python绑定释放GIL，保证多线程并发性能。PDF支持内置，文本型PDF可直接本地转换，无需OCR服务。benchmark显示，anydoc在14种格式的测试中全面领先，综合得分81分，远超其他工具。

示例速览

bash
npx skills add firecrawl/anydoc
bash
npx @firecrawl/anydoc report.docx               # Markdown to stdout
npx @firecrawl/anydoc slides.pptx -o slides.md  # or to a file
npx @firecrawl/anydoc - --format csv < data.csv # read stdin

如何上手

命令行用户可直接使用npx运行：npx @firecrawl/anydoc report.docx，首次运行会自动下载预编译二进制文件。Node.js项目需安装@firecrawl/anydoc包，然后调用toMarkdown函数，支持从文件路径或字节数据转换。Python用户安装firecrawl-anydoc后使用anydoc.to_markdown方法。WebAssembly版本适合浏览器环境，通过npm安装@firecrawl/anydoc-wasm包。所有绑定都提供格式检测功能，对于CSV等无签名格式的文档，需要显式指定格式名称。
