这是什么

Grok Build是SpaceXAI开发的基于终端的AI编码代理工具，以全屏TUI（文本用户界面）形式运行。它理解代码库、编辑文件、执行Shell命令、搜索网络并管理长任务，支持交互式、无头脚本/CI或嵌入编辑器（通过Agent Client Protocol）。本质是一个能‘动手’写代码、调试、甚至联网查资料的智能终端助手，让开发者无需离开命令行即可高效完成复杂任务。

核心功能

  • 全屏交互式TUI界面
  • 自动编辑文件与执行Shell命令
  • 联网搜索与多任务管理
  • 支持嵌入式Agent客户端协议

能用来做什么

适用于需要快速原型开发、自动化脚本编写、远程服务器调试或持续集成环境中的开发者。在终端工作流中，它能替代部分IDE功能，尤其适合习惯命令行操作、追求效率的高级用户。通过理解项目上下文，它能辅助重构、修复bug、生成测试用例，甚至在CI/CD流水线中自动处理构建问题，极大提升开发与运维效率。

技术亮点

项目采用Rust语言构建，确保高性能与内存安全。其架构模块化清晰：`xai-grok-pager`负责TUI渲染与交互，`xai-grok-shell`处理代理运行时与headless模式，`xai-grok-tools`封装文件编辑、终端执行等能力，`xai-grok-workspace`管理文件系统与版本控制。支持DotSlash实现工具沙箱化，保障执行安全性。同时，通过MCP（Model Control Protocol）扩展技能与插件，具备高度可定制性，是面向未来AI原生开发工具的典范。

如何上手

安装推荐直接使用官方脚本：`curl -fsSL https://x.ai/cli/install.sh | bash`（macOS/Linux）或 `irm https://x.ai/cli/install.ps1 | iex`（Windows）。安装后输入`grok --version`验证。首次运行会自动打开浏览器认证。若需从源码构建，先安装Rust和DotSlash（`cargo install dotslash`），再运行`cargo run -p xai-grok-pager-bin`启动TUI界面。
