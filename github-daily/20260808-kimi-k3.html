这是什么

Kimi K3 是由 Moonshot AI 开发的开源前沿智能模型，也是目前该团队最强大的成果。它是一个原生多模态智能体模型，总参数量高达 2.8 万亿，但每次推理只激活其中约 1040 亿个参数，这种设计既保证了强大的计算能力，又提高了效率。它支持长达 100 万 token 的上下文窗口，意味着它可以一次性阅读和理解海量的文本、图像和视频内容。与传统模型不同，Kimi K3 具备原生视觉能力，能够直接理解多模态信息，并在长周期的编程、知识工作和推理任务中自主运行。它采用了创新的 Kimi Delta Attention 和 Attention Residuals 架构，结合稳定的 Latent MoE 框架，显著提升了扩展效率。作为全球首个开源的 3T 级模型，Kimi K3 旨在将前沿智能能力开放给研究者和开发者，推动人工智能在复杂工程、深度研究和创意工作等领域的广泛应用与创新。

核心功能

  • 原生多模态理解，支持文本、图像和视频的深度融合
  • 百万 token 超长上下文窗口，处理海量信息无压力
  • 2.8 万亿参数 MoE 架构，激活参数仅 1040 亿，高效强大
  • 自主智能体能力，支持长周期编程与知识工作

能用来做什么

Kimi K3 适用于需要处理复杂、长周期任务的场景。在编程领域，它能自主导航大型代码库，完成从 GPU 内核优化到芯片设计等深度工程任务，减少人工干预。在知识工作中，它能生成包含交互式可视化、仪表板和视频编辑的深度研究报告。对于研究人员，其百万字上下文允许分析整本著作或大量文献。企业可利用其进行自动化工作流开发，提升研发效率。开源特性使其成为学术研究和模型微调的理想基座，推动前沿智能技术的普及与创新应用。

技术亮点

Kimi K3 的技术突破主要体现在架构创新与规模效应。首先，它采用了 Kimi Delta Attention (KDA) 和 Attention Residuals (AttnRes)，结合 Stable LatentMoE 框架，实现了 896 个专家中激活 16 个的高效稀疏计算，相比前代效率提升约 2.5 倍。其次，其 2.8 万亿总参数与 1040 亿激活参数的组合，在保持高性能的同时优化了推理成本。第三，原生多模态架构使其能统一处理文本、图像和视频，无需额外模块即可理解复杂视觉信息。第四，100 万 token 的上下文窗口配合 MXFP4/MXFP8 量化训练技术，确保了在超长序列处理中的精度与效率平衡。这些创新共同构成了其作为全球首个开源 3T 级模型的竞争力。

示例速览

python
import openai

def chat_with_preserved_thinking(client: openai.OpenAI, model_name: str):
    messages = [
        {
            "role": "user",
            "content": "Tell me three random numbers."
        },
        {
            "role": "assistant",
            "reasoning_content": "I'll start by listing five numbers: 473, 921, 235, 215, 222, and I'll tell you the first three.",
            "content": "473, 921, 235"
        },
        {
            "role": "user",
            "content": "What are the other two numbers you have in mind?"
        }
    ]

    response = client.chat.completions.create(
        model=model_name,
        messages=messages,
        stream=False,
        max_tokens=4096,
        reasoning_effort="max",
    )
    # the assistant should mention 215 and 222 that appear in the prior reasoning content
    print(f"response: {response.choices[0].message.reasoning}")
    return response.choices[0].message.content
